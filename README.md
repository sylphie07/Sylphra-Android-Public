# Sylphra Launcher

**Un launcher independiente para Android basado en Horizon Android.** Sylphra busca acercar la experiencia de Horizon a dispositivos Android, con una interfaz adaptada al móvil y funciones propias desarrolladas para este proyecto.

> **Proyecto independiente y no oficial.** Sylphra Launcher es creado y mantenido por **Sylphie (@sylphie07)**. No es un producto oficial de Horizon, no está desarrollado, patrocinado ni respaldado por los equipos de Horizon, y no representa una colaboración con ellos. La relación con Horizon es técnica: Sylphra toma como base el proyecto Horizon y su port para Android, respetando sus créditos y licencias.

## ¿Qué es Sylphra?

Sylphra es un launcher Android construido sobre el trabajo de Horizon y su adaptación a Android. Su objetivo es ofrecer una experiencia cómoda en teléfonos y tabletas, además de incorporar mejoras y características propias.

El proyecto se desarrolla de manera independiente. Las decisiones, el diseño de Sylphra, su integración, sus funciones específicas y su distribución son responsabilidad de su creador.

## Características

- **Experiencia adaptada a Android:** interfaz y controles pensados para pantallas táctiles.
- **Minecraft Java ejecutado mediante Horizon:** Sylphra utiliza como base el motor/proyecto Horizon, reescrito en Rust.
- **Skins personalizadas:** compatibilidad con skins propias en mundos de un jugador y en servidores multijugador, según las pruebas realizadas.
- **Desarrollo centrado en móviles:** mejoras y ajustes orientados a que la experiencia sea práctica en dispositivos Android.
- **Proyecto en evolución:** se incorporan funciones y mejoras progresivamente.

Las funciones pueden variar entre versiones. Consulta las notas de cada publicación para conocer los cambios, requisitos y limitaciones de esa versión.
